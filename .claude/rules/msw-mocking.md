# MSW-моки

- Хендлеры — `src/shared/mocks/handlers.ts`, экспорт массива `HttpHandler[]`.
  Регистрация воркера — `src/shared/mocks/browser.ts`.
- Один хендлер = один эндпоинт сущности, физически рядом с сущностью удобнее
  собирать через ре-экспорт в `handlers.ts` (`entities/order/mocks.ts` и т.п.),
  не сваливать всё в один файл по мере роста.
- Моки должны имитировать реальное поведение честно: задержки через
  `delay()`, ошибочные ответы иногда (не только happy path) — фронт пишем с
  настоящими loading/error state RTK Query, не заглушками.
- Смена статусов заказа / тикающая геопозиция — через `setInterval`/таймеры
  внутри хендлера или через отдельный стрим-эмулятор в `shared/mocks/`, не
  внутри компонентов.
- MSW включается только в dev (`import.meta.env.PROD` гейт в `src/main.tsx`).
  В проде бэкенда нет по определению — не пытаться дергать реальный API.
