# Проверки перед коммитом

Тестов пока нет (greenfield-скаффолд) — минимум перед любым коммитом:

```
npm run build   # tsc -b && vite build — типы + прод-сборка
npm run lint    # oxlint
```

Оба должны быть зелёными. Если добавляется тестовый раннер (Vitest и т.п.) —
завести `npm run test` и обновить этот файл + `CLAUDE.md`.

Для фич с реальным UI-поведением — прогонять глазами через dev-сервер
(`npm run dev`), мобильный вьюпорт в первую очередь (mobile-first). Не
полагаться только на typecheck как на доказательство того, что фича работает.
