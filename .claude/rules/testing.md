# Проверки перед коммитом

Тестов пока нет (greenfield-скаффолд) — минимум перед любым коммитом:

```
npm run build   # tsc -b && vite build — типы + прод-сборка
npm run lint    # oxlint
```

Оба должны быть зелёными. Если добавляется тестовый раннер (Vitest и т.п.) —
завести `npm run test` и обновить этот файл + `CLAUDE.md`.

Для фич с реальным UI-поведением — прогонять глазами через dev-сервер
(`npm run dev`), мобильный вьюпорт в первую очередь (mobile-first). Не
полагаться только на typecheck как на доказательство того, что фича работает.

## Визуальная проверка (Playwright)

`playwright` — devDependency, Chromium уже скачан локально
(`npx playwright install chromium`). Нет постоянного MCP-сервера в контексте —
для проверки пишется одноразовый Node-скрипт через `require('playwright')`
(запуск браузера, `page.goto`, `page.screenshot`, чтение `console`-ошибок).
Ничего не коммитить как переиспользуемый раннер, пока не понадобится
регулярно — одноразовые скрипты в scratchpad.

Обязательно проверять `page.on('console', ...)` на ошибки — экран может
отрендериться визуально нормально, а под капотом падать запрос/редьюсер.
