# Git-workflow

- **`main`** — стабильная ветка, всегда в рабочем состоянии (build + typecheck
  зелёные).
- Фичи — в `feature/<slug>` (slug = пункт из `docs/roadmap.md`, kebab-case).
  Не коммитить напрямую в `main`, кроме самого каркаса и мелких фиксов,
  согласованных с Eugene.
- **Conventional Commits**: `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`,
  `style:`, `test:` + короткий scope при необходимости (`feat(order-flow): ...`).
- Коммиты атомарные — один коммит = одно логическое изменение, не сваливать
  фичу в один гигантский коммит.
- Архитектурные решения — в `docs/decisions.md` (ADR-лог), не только в
  сообщении коммита: коммит объясняет *что*, ADR объясняет *почему*.
- Мёрж фичи в `main` — после явного аппрува Eugene/Миши на реализованный кусок.
- Не форсить пуш, не переписывать историю `main` без явного запроса.
