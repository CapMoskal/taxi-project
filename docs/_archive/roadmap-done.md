# Roadmap — архив «Готово»

Подробные записи по каждому завершённому пункту `docs/roadmap.md` — что
именно сделано, какие файлы/паттерны, как проверено в браузере. Вынесено
сюда при компакте 2026-07-23, когда список «Готово» разросся настолько, что
занимал основную часть токенов при чтении `roadmap.md` — сам файл
предназначен для быстрой навигации по плану, а не как ADR-лог (для решений
и их «почему» — `decisions.md`).

- [x] Карта следует теме приложения: MapTiler-стиль переключается вместе

      переналагается заново с цветом, ре-резолвленным из
      `var(--foreground)` в момент переналожения (не кэшируется). Найден
      и исправлен баг при ручной проверке (не через e2e — приложение не

      исчезающий стиль и терялось. Исправлено на постоянный слушатель
      `styledata` с перепроверкой `isStyleLoaded()` внутри себя. Без
      отдельного e2e на сам свап (под моками оба стиля неразличимы, живого
