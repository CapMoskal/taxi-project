# Roadmap

Фича за фичей, план меняется по ходу — не хранить в CLAUDE.md. Порядок —
рабочая гипотеза, пересматривать при новых вводных от Eugene/Миши.

Каждый пункт — отдельная `feature/<slug>` ветка, план-mode перед стартом,
явный аппрув перед мёржем в `main` (см. `.claude/rules/git-workflow.md`).

## Готово

- [x] Каркас: Vite + React + TS + Tailwind + shadcn/ui + RTK + MSW + XState +
      MapLibre + Motion + PWA-плагин. Память проекта (CLAUDE.md/rules/docs).
- [x] Дизайн-токены: изумрудный `--primary`, мягкие скругления (дефолт),
      Geist. Детали и точные oklch-значения — `.claude/rules/design-tokens.md`.
- [x] Машина состояний заказа (XState, `features/order-flow`) + пустой экран
      карты (`shared/map/MapCanvas`, demo-style MapLibre без ключа) +
      dev-only debug-панель для прогона состояний. `screens/order/OrderScreen`
      подключён в `App.tsx`. Проверено в браузере (Playwright) — полный цикл
      idle → ... → done → RESET → idle без новых консольных ошибок.
- [x] Реальный MapTiler style (`basic-v2`) вместо demo-style + rAF-трекинг
      маркера водителя по полилайну (`useAnimatedPosition`,
      `useDriverLocationSimulator`) с throttled-синком в XState-контекст и
      `map.fitBounds()` по текущему отрезку маршрута. Проверено в браузере —
      маркер виден на всём протяжении обеих ног (`enRoute`/`inRide`).
- [x] Класс такси / выбор точки подачи: центр-пин + drag карты для точки
      назначения, bottom-sheet (Motion) с классами и MSW-ценой от расстояния
      A→B. Первый реальный RTK Query api-slice (`entities/ride-class`) —
      warning про пустой store наконец исчез. Пины A/B + линия маршрута на
      карте. Проверено в браузере — drag, реальный сетевой запрос через MSW,
      полный цикл до `searchingDriver`, без консольных ошибок.
- [x] Поиск машины / назначение водителя: `entities/driver` +
      `DriverSearchPanel` (MSW-задержка ~1.5–2.5с, ~20% случайных отказов с
      кнопкой «Повторить поиск») + `DriverCard` (аватар-инициалы, машина,
      номер, рейтинг — держится на экране до `inRide`). Debug-панель для
      `searchingDriver` заменена настоящим UI. Проверено в браузере — 4
      прогона, все 3 демо-водителя из пула встречались, ноль консольных
      ошибок.
