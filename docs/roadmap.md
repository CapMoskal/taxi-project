# Roadmap

Фича за фичей, план меняется по ходу — не хранить в CLAUDE.md. Порядок —
рабочая гипотеза, пересматривать при новых вводных от Eugene/Миши.

Каждый пункт — отдельная `feature/<slug>` ветка, план-mode перед стартом,
явный аппрув перед мёржем в `main` (см. `.claude/rules/git-workflow.md`).

## Готово

- [x] Каркас: Vite + React + TS + Tailwind + shadcn/ui + RTK + MSW + XState +
      MapLibre + Motion + PWA-плагин. Память проекта (CLAUDE.md/rules/docs).

## Дальше

1. **Дизайн-токены** — зафиксировать точную палитру/шрифт/скругления светлого
   минимализма в `.claude/rules/design-tokens.md` и `src/index.css` (сейчас там
   нейтральный дефолт shadcn preset Nova).
2. **Машина состояний заказа (XState)** — `features/order-flow`: поиск точки →
   выбор класса → поиск машины → назначена → едет → в поездке → завершено/оплата.
   Пустой экран карты (MapLibre) под неё, без стилизации — каркас флоу.
3. **Экран карты + интерполяция маркера** — `shared/map`, свой `style.json`
   (MapTiler free), хук `requestAnimationFrame`-трекинга по полилайну.
4. **Класс такси / выбор точки подачи** — bottom-sheet (Motion), MSW-моки для
   доступных классов и цены.
5. **Поиск машины / назначение водителя** — MSW имитирует задержку и подбор,
   карточка водителя (аватар, машина, рейтинг — заглушки).
6. **Поездка в реальном времени** — тикающая геопозиция водителя, статусы заказа.
7. **Оплата / оценка поездки** — экран завершения, чек, рейтинг водителя.
8. **Профиль пользователя**.
9. **История поездок**.
10. **PWA-полировка** — иконки, splash, offline-заглушка.

## Открытое

- Точные дизайн-токены (см. п.1) — согласовать с Eugene перед стилизацией любого
  экрана.
- MapTiler API-ключ / свой style.json — нужен перед пунктом 3.
