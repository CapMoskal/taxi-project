# Roadmap

Фича за фичей, план меняется по ходу — не хранить в CLAUDE.md. Порядок —
рабочая гипотеза, пересматривать при новых вводных от Eugene/Миши.

Каждый пункт — отдельная `feature/<slug>` ветка, план-mode перед стартом,
явный аппрув перед мёржем в `main` (см. `.claude/rules/git-workflow.md`).

## Готово

- [x] Каркас: Vite + React + TS + Tailwind + shadcn/ui + RTK + MSW + XState +
      MapLibre + Motion + PWA-плагин. Память проекта (CLAUDE.md/rules/docs).
- [x] Дизайн-токены: изумрудный `--primary`, мягкие скругления (дефолт),
      Geist. Детали и точные oklch-значения — `.claude/rules/design-tokens.md`.

## Дальше

1. **Машина состояний заказа (XState)** — `features/order-flow`: поиск точки →
   выбор класса → поиск машины → назначена → едет → в поездке → завершено/оплата.
   Пустой экран карты (MapLibre) под неё, без стилизации — каркас флоу.
2. **Экран карты + интерполяция маркера** — `shared/map`, свой `style.json`
   (MapTiler free), хук `requestAnimationFrame`-трекинга по полилайну.
3. **Класс такси / выбор точки подачи** — bottom-sheet (Motion), MSW-моки для
   доступных классов и цены.
4. **Поиск машины / назначение водителя** — MSW имитирует задержку и подбор,
   карточка водителя (аватар, машина, рейтинг — заглушки).
5. **Поездка в реальном времени** — тикающая геопозиция водителя, статусы заказа.
6. **Оплата / оценка поездки** — экран завершения, чек, рейтинг водителя.
7. **Профиль пользователя**.
8. **История поездок**.
9. **PWA-полировка** — иконки, splash, offline-заглушка.
